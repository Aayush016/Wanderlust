Wanderlust 🌍

A full-stack MERN travel listing application where users can explore, create, and manage travel destinations.

🚀 Features

- Browse travel listings
- Create, edit, and delete listings
- User authentication
- Reviews and ratings
- Image uploads
- Responsive UI

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript, EJS
Backend: Node.js, Express.js
Database: MongoDB
Authentication: Passport.js
